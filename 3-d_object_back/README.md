# 3D_object_back

Exhibition & object management backend for the 3DGS Memory Lab — Java · Spring (Maven).

Serves the studio frontend (`../3-d-objiect-studio/`) and stores the metadata
behind AI-generated 3D exhibits (see `../3-d_object_ai_back/` for how those
are produced).

```bash
mvn spring-boot:run
```

Part of [3dgs-memory-lab](https://github.com/ecoreal/3dgs-memory-lab) — the
R&D lab behind [`yifang-pavilion`](https://github.com/ecoreal/yifang-pavilion).
