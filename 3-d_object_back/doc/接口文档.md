# API 接口文档

## 基础信息

- **Base URL**: `http://localhost:8080`
- **Content-Type**: `application/json`
- **认证方式**: JWT Bearer Token

## 认证说明

### 携带 Token 的请求

需要认证的接口需要在 HTTP Header 中携带 Token：

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### Token 获取

通过登录接口获取 Token，Token 有效期为 24 小时。

## 2. 模型相关接口

### 2.1 创建模型（上传）

**接口地址**: `POST /api/models/upload`

**是否需要认证**: 是

**请求参数**:
```json
{
  "model": {
    "title": "老式留声机",
    "story": "这台留声机见证了1920年代的爵士乐盛世",
    "productionYear": 1925,
    "categoryId": 1,
    "thumbnailUrl": "http://localhost:8080/uploads/workshop/uuid.jpg",
    "isPublic": false
  },
  "tags": ["复古", "1920年代", "音乐"],
  "modelFiles": [
    {
      "fileUrl": "https://ai.example.com/result/model.glb",
      "fileType": "GLB",
      "originalName": "model.glb"
    }
  ]
}
```

`modelFiles` 为可选字段。AI 生成流程已经拿到 `modelUrl` 时，可以在创建模型时一并传入；后端会在模型创建成功后写入 `model_files` 表。若传入的是远程 `http(s)` 地址，后端会先下载；如果下载结果是 zip，会解压出其中的 `glb/gltf/obj/ply` 文件，保存到 `/uploads/models/{mid}/` 后再写库。

**成功响应** (200):
```json
{
  "mid": 10,
  "uid": 1,
  "categoryId": 1,
  "title": "老式留声机",
  "story": "这台留声机见证了1920年代的爵士乐盛世",
  "productionYear": 1925,
  "renderStatus": "waiting",
  "isPublic": false,
  "thumbnailUrl": "http://localhost:8080/uploads/workshop/uuid.jpg",
  "createdAt": "2024-03-14T11:00:00",

}
```

## 5. 模型文件相关接口

### 5.1 绑定已有模型文件 URL

**接口地址**: `POST /api/model-files/bind-url`

**是否需要认证**: 是

**请求参数**:
```json
{
  "mid": 10,
  "fileUrl": "https://ai.example.com/result/model.glb",
  "fileType": "GLB",
  "originalName": "model.glb"
}
```

**字段说明**:
- `mid`: 模型 ID。
- `fileUrl`: 已生成的 GLB/OBJ/PLY/GLTF 文件地址或 AI 返回的 zip 下载地址，支持 `http(s)`、`/uploads/...`、`uploads/...`。
- `fileType`: 可选，不传时根据 URL 后缀推断。
- `originalName`: 可选，不传时根据 URL 文件名推断。

处理规则：
- `http(s)` 远程地址会被后端下载到本地。
- 如果远程内容是 zip，后端会解压出第一个 `glb/gltf/obj/ply` 模型文件。
- 最终写入 `model_files.file_path` 的是 `/uploads/models/{mid}/...` 下可直接预览的模型文件路径。

**成功响应** (200):
```json
{
  "id": 1,
  "mid": 10,
  "fileType": "GLB",
  "filePath": "uploads/models/10/8f41c7e2-8dbf-4d42-a3fa-d87e10c9a52a.glb",
  "originalName": "model.glb",
  "fileSize": null,
  "contentType": "model/gltf-binary",
  "createdAt": "2024-03-14T11:00:00"
}
```

### 11.5 提交腾讯混元 3D 生成任务

**接口地址**: `POST /hunyuan3d/submit`

**是否需要认证**: 否

**说明**: 按 AI 服务定义代理提交混元 3D 任务。Java 后端会先校验 `data:image/...;base64,...` 格式、图片类型、Base64 合法性、大小和单边分辨率，再代理请求 AI 服务。

**请求参数**:
```json
{
  "image_base64": "data:image/png;base64,iVBORw0KGgoAAA...",
  "generate_type": "Normal"
}
```

**参数说明**:
- `image_base64`: 必填，仅支持 `jpg`、`jpeg`、`png`、`webp`
- 图片大小: 不超过 6MB
- 单边分辨率: 128 到 5000 像素

## AI 接口接入说明

这次后端的接入方式是代理模式，不是把 AI 逻辑直接写进 Spring Boot：

1. Spring Boot 新增了 `/hunyuan3d/*`、`/seed3d/*` 和 `/seedream/*` 端点，对外暴露统一接口。
2. 控制层接收 JSON 请求后，交给 `AiGatewayService` 做参数校验。
3. `AiGatewayService` 负责校验图片 Data URI 格式、图片类型、Base64、图片尺寸、大小、总像素、宽高比和 `size/generate_type` 等参数。
4. 校验通过后，通过 `RestTemplate` 转发到 AI 服务。目标地址由以下配置动态拼接：
   - `app.ai.scheme`
   - `app.ai.port`
   - `app.ai.server-ip`
   - `app.ai.local-ip`
   - 环境变量 `3D_OBJECT_RUN_ENV`
5. 地址选择规则如下：
   - 当 `3D_OBJECT_RUN_ENV=SERVER` 且 `app.ai.server-ip` 有值时，使用服务器 IP
   - 其他情况下优先使用 `app.ai.local-ip`
   - `app.ai.local-ip` 为空时，自动探测本机 IPv4
6. 原有 `/api/media/enhance` 和 `/api/media/colorize` 没删，而是改成复用这套代理服务，兼容旧的文件上传调用方式。

### 我是怎么用这套接口的

如果前端已经拿到本地图片文件，有两种用法：

1. 新接口用法
   - 前端先把图片转成 `Base64 Data URI`
   - 直接请求 `/hunyuan3d/submit`、`/seed3d/submit`、`/seedream/enhance` 或 `/seedream/colorize`
   - 适合和 AI 服务文档保持一致

2. 兼容旧接口用法
   - 前端继续用 `multipart/form-data` 上传文件到 `/api/media/enhance` 或 `/api/media/colorize`
   - 后端内部把文件转成 Base64 再转发给 AI 服务
   - 适合当前已有页面不改请求结构直接复用

前端如果要发起 3D 生成，典型流程如下：

```text
选择图片 -> 转成 Base64 -> POST /hunyuan3d/submit -> 拿到 job_id -> 轮询 /hunyuan3d/query/{jobId} -> 取回 glb/obj 下载地址
```

前端如果要使用豆包 3D 生成，典型流程如下：

```text
选择图片 -> 转成 Base64 -> POST /seed3d/submit -> 拿到 job_id -> 轮询 /seed3d/query/{jobId} -> 取回 zip/glb 下载地址
```

前端如果只是做图片预处理，典型流程如下：

```text
选择图片 -> 转成 Base64 -> POST /seedream/enhance 或 /seedream/colorize -> 拿到 image_url -> 展示处理结果
```

## 前端集成示例

### JavaScript (Fetch API)

```javascript
// 登录示例
async function login(email, password) {
  const response = await fetch('http://localhost:8080/api/users/login', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      account: email,
      password: password
    })
  });

  if (response.ok) {
    const data = await response.json();
    localStorage.setItem('token', data.token);
    return data;
  } else {
    throw new Error('登录失败');
  }
}

// 携带 Token 的请求示例
async function getMyModels() {
  const token = localStorage.getItem('token');

  const response = await fetch('http://localhost:8080/api/models/my', {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });

  if (response.ok) {
    return await response.json();
  } else if (response.status === 401) {
    // Token 过期，需要重新登录
    window.location.href = '/login';
  }
}

// 上传文件示例
async function uploadAvatar(file) {
  const token = localStorage.getItem('token');
  const formData = new FormData();
  formData.append('file', file);

  const response = await fetch('http://localhost:8080/api/upload/avatar', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`
    },
    body: formData
  });

  if (response.ok) {
    const data = await response.json();
    return data.url;
  }
}
```

## 注意事项

1. **Token 管理**: 前端需妥善保存 Token，并在 Token 过期时提示用户重新登录
2. **错误处理**: 建议对所有请求进行统一的错误处理
3. **文件上传**: 注意文件大小限制（最大 50MB）
4. **跨域配置**: 开发环境已配置 CORS，生产环境需要根据实际域名调整
5. **安全性**: 生产环境建议使用 HTTPS 协议
