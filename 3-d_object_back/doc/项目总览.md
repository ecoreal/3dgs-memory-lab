# 3D Object Backend 项目文档

## 项目概述

这是一个基于 Spring Boot 的 3D 模型管理系统后端项目，提供用户认证、模型上传、社交互动等核心功能。项目采用前后端分离架构，通过 RESTful API 与前端交互。

### 核心功能

- **用户系统**：注册、登录、个人信息管理
- **3D 模型管理**：模型上传、编辑、分类、标签管理
- **社交功能**：点赞、收藏、评论
- **文件管理**：支持多种 3D 格式（GLB、OBJ）
- **导出任务**：模型导出和邮件发送
- **分类系统**：赛博艺术、复古家电、工业遗迹、生活百货

## 技术栈

### 后端框架
- **Spring Boot 3.0.2** - 核心框架
- **Spring Data JPA** - 数据持久化
- **Spring Security Crypto** - 密码加密
- **MySQL 8.0+** - 关系型数据库

### 安全认证
- **JWT (JJWT 0.11.5)** - Token 认证
- **自定义拦截器** - 接口权限控制

### 开发工具
- **Lombok** - 简化 Java 代码
- **Maven** - 项目构建管理
- **Java 17** - 开发语言

## 快速开始

### 环境要求

- Java 17+
- Maven 3.6+
- MySQL 8.0+

### 配置数据库

修改 `src/main/resources/application.properties`：

```properties
spring.datasource.url=jdbc:mysql://your-host:3306/your-database
spring.datasource.username=your-username
spring.datasource.password=your-password
```

### 启动项目

```bash
# 编译打包
mvn clean package

# 运行项目
mvn spring-boot:run

# 或直接运行 JAR
java -jar target/_3dObject-0.0.1-SNAPSHOT.jar
```

项目默认运行在 `http://localhost:8080`

## 主要特性

### 1. JWT 认证机制
- 使用 JJWT 库实现 Token 生成和验证
- Token 有效期 24 小时
- 请求头格式：`Authorization: Bearer <token>`

### 2. 文件上传
- 支持最大 50MB 文件上传
- 自动生成 UUID 文件名
- 支持动态路径分类（avatar、workshop）
- 文件访问路径：`/uploads/{type}/{filename}`

### 3. 模型状态管理
- waiting：等待处理
- processing：处理中
- success：处理成功
- failed：处理失败

### 4. 社交功能
- 支持点赞（LIKE）
- 支持收藏（COLLECT）
- 评论系统
- 实时统计数据

### 5. CORS 跨域支持
- 允许所有来源
- 支持 GET、POST、PUT、DELETE、OPTIONS 方法
- 支持认证信息传递

## 接口鉴权

### 公开接口（无需 Token）
- `/api/users/login` - 登录
- `/api/users/register` - 注册
- `/api/categories` - 获取分类列表
- `/api/models/public` - 获取公开模型
- `/api/model-tags/model/*` - 获取模型标签
- `/api/model-files/model/*` - 获取模型文件
- `/api/model-audios/model/*` - 获取模型音频

### 需要认证的接口
- `/api/users/me` - 获取当前用户
- `/api/users/update` - 更新用户信息
- `/api/models/upload` - 上传模型
- `/api/models/update/*` - 更新模型
- `/api/models/my` - 获取我的模型
- `/api/actions/*` - 社交功能
- `/api/comments/*` - 评论功能
- 其他业务接口

## 开发建议

1. **密码安全**：建议使用 Spring Security 的 BCryptPasswordEncoder 进行密码加密
2. **JWT 密钥**：生产环境应将密钥移至配置文件并使用环境变量
3. **异常处理**：建议添加全局异常处理器统一返回格式
4. **日志记录**：添加完善的日志记录机制
5. **单元测试**：为关键业务逻辑添加单元测试
6. **API 文档**：可集成 Swagger/SpringDoc 自动生成 API 文档
